# Chat Interface React Project

A simple React-based chat interface built with Vite.

## Features

- Chat message list with sender distinction (me vs. bot)
- Message input field
- Sidebar for chat history
- Simulated bot responses

## Setup and Running

1. **Install dependencies:**

   ```bash
   npm install
   ```

2. **Run the development server:**

   ```bash
   npm run dev
   ```

3. **Build for production:**

   ```bash
   npm run build
   ```

4. **Preview the production build:**

   ```bash
   npm run preview
   ```

## Note on Styling

This project uses Tailwind CSS classes for styling. To see the full styling, ensure Tailwind CSS is correctly configured in your project.
